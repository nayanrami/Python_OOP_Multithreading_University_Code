# Generator Functions and Iterators

An iterator implements __iter__() and __next__(). A generator is a concise way to create an iterator using yield. Both support lazy processing and can reduce memory usage.

## Learning Outcomes
After completing this folder, students should be able to:
- explain the core concept using Python terminology;
- trace program execution and object state;
- modify the example for a new requirement;
- identify common implementation mistakes;
- apply the concept to a design/algorithm problem.
