## Suggested Laboratory Pattern
1. Run the basic example.
2. Ask students to trace the state on paper.
3. Modify one requirement.
4. Run the real-world and advanced examples.
5. Attempt the PRACTICE questions.
6. Study the LeetCode-style implementation last.
